# 🤖 LangGraph AI Agent (TypeScript) on AWS AgentCore

This project is an AI agent built using **[LangGraph](https://github.com/langchain-ai/langgraph)** in **TypeScript**, designed to run on the **AWS AgentCore runtime**. It enables structured, graph-based reasoning and control over LLM-based workflows.

---

## 🚀 Features

- Built with **LangGraph** for composable, graph-based agent logic
- Written in **TypeScript** with clean modular structure
- Hosted using **AWS AgentCore runtime**
- Easy to build and run locally or in the cloud
